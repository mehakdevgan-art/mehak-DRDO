# Database Schema Documentation

The DPM-DSS utilizes PostgreSQL as its primary relational datastore. Below is the simplified logical schema detailing the core entities and their relationships.

## Table: `users`
Stores all system users and their assigned roles for RBAC.
- `id` (UUID, Primary Key)
- `email` (String, Unique)
- `password_hash` (String)
- `full_name` (String)
- `role` (Enum: Administrator, Project Director, Project Manager, etc.)
- `department_id` (UUID, Foreign Key -> `departments.id`)
- `created_at` (Timestamp)

## Table: `departments`
Represents the organization's divisions (e.g., AI Lab, Radar Systems).
- `id` (UUID, Primary Key)
- `name` (String)
- `head_id` (UUID, Foreign Key -> `users.id`)
- `total_budget_allocated` (Decimal)

## Table: `projects`
Stores the core project definitions and their current health metrics.
- `id` (UUID, Primary Key)
- `name` (String)
- `description` (Text)
- `department_id` (UUID, Foreign Key -> `departments.id`)
- `manager_id` (UUID, Foreign Key -> `users.id`)
- `status` (Enum: Planning, In Progress, Delayed, Completed)
- `risk_level` (Enum: Low, Medium, High)
- `budget_allocated` (Decimal)
- `budget_spent` (Decimal)
- `start_date` (Date)
- `target_end_date` (Date)

## Table: `milestones`
Tracks critical deliverables within a project.
- `id` (UUID, Primary Key)
- `project_id` (UUID, Foreign Key -> `projects.id`)
- `title` (String)
- `status` (Enum: Pending, In Progress, Completed, Blocked)
- `target_date` (Date)
- `completion_date` (Date, Nullable)

## Table: `ai_insights`
Stores historical and active recommendations generated by the Decision Support Engine.
- `id` (UUID, Primary Key)
- `project_id` (UUID, Foreign Key -> `projects.id`)
- `insight_type` (String)
- `title` (String)
- `description` (Text)
- `confidence_score` (Float)
- `priority` (Enum: Low, Medium, High)
- `generated_at` (Timestamp)

## Table: `audit_logs`
Immutable ledger of all critical system activities for compliance.
- `id` (UUID, Primary Key)
- `user_id` (UUID, Foreign Key -> `users.id`)
- `action_type` (String - e.g., 'BUDGET_UPDATE', 'RISK_ESCALATION')
- `entity` (String - e.g., 'projects')
- `entity_id` (UUID)
- `old_values` (JSONB)
- `new_values` (JSONB)
- `timestamp` (Timestamp)

---

## Relationships Summary
- A **Department** has many **Users**.
- A **Department** has many **Projects**.
- A **Project** has one **Manager** (User).
- A **Project** has many **Milestones**.
- A **Project** has many **AI Insights**.
- A **User** generates many **Audit Logs**.
